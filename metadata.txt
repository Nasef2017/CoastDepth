about=CoastDepth is an independent, open-source QGIS plugin for retrieving, masking, and processing coastal Satellite-Derived Bathymetry (SDB) (~100 m resolution) provided by the E.U. Copernicus Marine Service (CMEMS). It is an unofficial community tool that provides streamlined access to Copernicus coastal bathymetry datasets: Optical RTE physics-based inversion, Wave Kinematics, and Intertidal mapping. Features include precise polygon masking, fault-tolerant batch downloading with automatic skipping of unmapped areas, encrypted credentials via QGIS Authentication Manager, and export to analysis-ready GeoTIFF and CF-compliant NetCDF with full cryptographic provenance (SHA-256) and citations. Developed by Mohamed Aly Nasef; documentation and vibe coding by ChatGPT. Requires Python 3.10+ with copernicusmarine in an isolated environment.

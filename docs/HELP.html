CoastDepth — Copernicus Marine SDB

Version 0.2.5

Data source: E.U. Copernicus Marine Service. This independent plugin retrieves existing Copernicus Marine coastal satellite-derived bathymetry (SDB); it does not generate a new SDB estimate and is not an official or endorsed Copernicus application.

Datasets

  • Optical RTE: Physics-based optical bathymetry from inversion of the Radiative Transfer Equation (RTE).
    Dataset ID: cmems_obs-sdb_glo_phy_irte_my_100m-l4-s2_static
  • Wave Kinematics: Bathymetry derived from wave kinematics.
    Dataset ID: cmems_obs-sdb_glo_phy_wk_my_100m-l4-s2_static
  • Intertidal: Bathymetry of intertidal areas between tidal levels.
    Dataset ID: cmems_obs-sdb_glo_phy_it_my_100m-l4-s2_static

How to use

Choose an ROI layer, polygon mask or layer extent, and optionally Selected Features only. Select an output folder and format, then Run. Sign in when asked. Progress, Cancel and safe error messages use the native Processing dialog. Transient network errors are retried; a failed run can be run again with a new run folder.

Outputs

Only Height layers are added to QGIS. Quality_indicator, SDB_type when supplied, NetCDF/GeoTIFF files, metadata/provenance and a safe JSONL log remain in the output folder. Folders and layers use Optical RTE, Wave Kinematics and Intertidal names. Polygon holes and nodata are preserved; values, signs and vertical datum are not changed.

Limitations

Static coastal coverage, nominally about 100 m. Availability varies by method and location. These data are not for navigation. Image acquisition dates are recorded only if supplied by the source; a documented image period is not treated as per-pixel acquisition evidence. The dependency check runs at plugin activation; missing packages show OSGeo4W Shell pip instructions. Libraries run in the private environment.

Data citation — applies to every dataset above

Global coastal satellite derived bathymetry static. E.U. Copernicus Marine Service Information (CMEMS). Marine Data Store (MDS). DOI: 10.48670/mds-00364. Include the actual access date and dataset ID/version from provenance when citing downloaded data.

The DOI identifies the parent product BATHYMETRY_GLO_PHY_COASTAL_L4_MY_016_001; the three datasets do not have separate Copernicus product DOIs.

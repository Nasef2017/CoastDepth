# Citation and attribution

## Data product

Use the parent product DOI and identify the actual dataset IDs and selected version from each run's provenance:

> Global coastal satellite derived bathymetry static. E.U. Copernicus Marine Service Information (CMEMS). Marine Data Store (MDS). https://doi.org/10.48670/mds-00364 (Accessed on 24 Oct 2026).

The date above is this project's catalogue verification date. For research using downloaded data, use the actual access date recorded in provenance. Separate dataset DOIs have not been invented.

For masked/converted outputs, the plugin records:

> Generated using E.U. Copernicus Marine Service Information; https://doi.org/10.48670/mds-00364

For redistribution of unmodified source information, or a scientific publication, choose the respective acknowledgement required by the [current agreement](https://marine.copernicus.eu/user-corner/service-commitments-and-licence) and [official citation guidance](https://help.marine.copernicus.eu/en/articles/4444611-citing-copernicus-marine-products-and-services). Include any relevant producer references supplied in PUM/QUID; do not substitute the plugin citation for the data citation.

## Software

Suggested descriptive citation:

> CoastDepth contributors (2026). CoastDepth, version 0.2.5 [QGIS plugin software].

No software DOI, public repository, registered release, institutional affiliation or named human author has been fabricated. Add the actual maintainer's name and an archived release URL/DOI when those exist. A machine-readable `CITATION.cff` is provided without invented author identities.
